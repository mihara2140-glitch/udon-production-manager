FEATURED PROJECT

製麺管理アプリ

製麺の条件・配合・評価を記録し、過去データを検索・比較できるWebアプリです。学習用のサンプルではなく、自分自身が実際の製麺作業で使うことを前提に改善しています。

01

製麺記録

日付、気温、湿度、熟成時間、茹で時間など、再現に必要な条件を保存。

02

評価・比較

6項目を10点満点で評価し、60点満点の総合点を自動集計。

03

検索・絞り込み

製麺番号、配合番号、日付、状態などから過去記録を探し、並び替え可能。

04

配合・粉管理

配合データと小麦粉銘柄を登録し、製麺記録とあわせて管理。

05

データ分析

pandasでデータを処理し、matplotlibで評価推移をグラフ化。

06

PC・スマホ対応

FlaskでWeb化し、PythonAnywhereへ公開。外出先からも利用可能。

DEVELOPMENT PROCESS

使いながら、必要な機能を足す。

最初から完成形を決めるのではなく、実際に使って感じた不便を次の改善につなげています。

  1. CSV製麺記録の保存からスタート
  2. Tkinter入力・閲覧をGUI化
  3. SQLite検索・管理しやすいDBへ移行
  4. pandas / matplotlib蓄積したデータを分析・可視化
  5. FlaskPC・スマホで使えるWebアプリへ
  6. DeployPythonAnywhereで公開・運用開始
